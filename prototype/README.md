# Bloom — Phase 0 Prototype

Runnable **look-and-feel** mock before the Godot + sim port. No build step.

## Run

```bat
run.bat
```

Or double-click `index.html` (Chrome/Edge recommended — ES modules need a local server on some browsers).

If the page is blank when opened via `file://`, use:

```bat
npx --yes serve .
```

Then open http://localhost:3000

## What to try

1. Click **Visit**, **Water**, **Feed** — watch XP, gauges, journal toasts.
2. **Raise lights** — lamp moves up, temp drops, cone changes.
3. **End day** — streak, coins, plants grow a node every few days.
4. **Upgrade Shop** — buy fan/reflector/mylar; see them appear in the room.
